# Connect 4

Une version moderne et complète du jeu Connect 4 built avec le framework LÖVE.

## Caractéristiques

- **Modes de jeu** : VS Humain, VS Ordinateur (10 niveaux de difficulté) et Multijoueur en ligne.
- **Interface** : Animations fluides, effets visuels et sonores intégrés.
- **Connectivité** : Jeu en ligne via des codes de salon privés.

## Comment jouer

### Commandes
| Action | Touche |
| :--- | :--- |
| **Déplacement** | `Flèches` ou `WASD` |
| **Placer un jeton** | `Espace`, `Entrée` ou `S` |
| **Plein écran** | `F11` |
| **Menu / Retour** | `Echap` |

### Installation
1. Téléchargez le compressé `Connect4.zip` depuis la section [Releases](https://github.com/Chixiisreallynotme/Connect4butdifferent/releases/tag/v1.0).
2. Lancez l'exécutable directement dedant.
