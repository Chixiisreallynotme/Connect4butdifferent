# 🔴🔵 Connect 4 — Pixel Art Edition

A vibrant, pixel-perfect Connect 4 game built with the **LÖVE** framework. Experience the classic strategy game with modern juice, smooth animations, and online multiplayer.

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Engine](https://img.shields.io/badge/engine-LÖVE-pink)
![License](https://img.shields.io/badge/license-MIT-green)

---

## ✨ Features

- **🎮 Three Game Modes:**
  - **VS Human:** Battle it out locally with a friend.
  - **VS CPU:** Challenge our adaptive AI with 10 levels of difficulty.
  - **Online Multiplayer:** Play with anyone in the world using private room codes.
- **🎨 Retro Aesthetics:** High-quality pixel art rendering with a dedicated pixel canvas pipeline.
- **✨ Dynamic Juiciness:** 
  - Smooth animations and transitions.
  - Screenshake and particle effects on every drop.
  - Dynamic shaders (CRT, Outline, Sparkles).
- **🔊 Immersive Audio:** Satisfying sound effects for every move and victory.
- **🌐 Online Powered by Supabase:** Seamless real-time matchmaking and state synchronization.

---

## 🚀 How to Play

### Controls
| Action | Key |
| :--- | :--- |
| **Move Selection** | `Left/Right` or `A/D` |
| **Drop Piece** | `Down/S`, `Space`, or `Enter` |
| **Fullscreen** | `F11` |
| **Menu / Back** | `Escape` |
| **Mouse Support** | Full point-and-click interface |

### Installation
1. Download the latest `connect4.exe` from the [Releases](https://github.com/Chixiisreallynotme/Connect4butdifferent/releases) page.
2. Run the executable and enjoy!
